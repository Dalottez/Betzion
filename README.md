# Betzion

Angular source for the Aviator game interface and supporting screens.

## Start locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Build

```bash
npm run build
```

## Important

This is a sanitized frontend distribution. It does not contain any backend, database, payment provider, callback/webhook, deployment configuration, credentials, or production API target. See [SANITIZATION.md](SANITIZATION.md) for the full scope.
